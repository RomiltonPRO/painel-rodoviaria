# 🚌 Painel Rodoviário

> Status do Projeto: 🚧 Em Desenvolvimento

O **Painel Rodoviário** é uma solução web moderna desenvolvida para otimizar o monitoramento de frotas e a exibição de horários em terminais rodoviários. O objetivo principal do projeto é resolver o problema de dessincronização de dados em tempo real, fornecendo aos passageiros e gestores uma interface clara, intuitiva e responsiva para o acompanhamento de partidas, chegadas, atrasos e plataformas de embarque.

## ✨ Funcionalidades

* [x] **Painel Dinâmico:** Exibição em tempo real dos horários de partidas e chegadas dos ônibus.
* [x] **Controle de Status:** Atualização instantânea sobre o estado das viagens (Confirmado, Atrasado, Embarcando ou Cancelado).
* [x] **Interface Responsiva:** Layout adaptável para TVs de terminais, monitores e dispositivos móveis.
* [x] **Gestão de Rotas:** Organização visual por empresas, destinos e plataformas de embarque.

## 🛠️ Tecnologias Utilizadas

Para o desenvolvimento deste painel, foram utilizadas as seguintes tecnologias fundamentais da web:

* **HTML5:** Estruturação semântica de todos os painéis e tabelas de horários.
* **CSS3:** Estilização moderna, uso de Flexbox/Grid e design focado na legibilidade de terminais.
* **JavaScript:** Lógica de programação para manipulação do DOM e atualização dinâmica dos dados.

## 🚀 Como executar o projeto

Para clonar e executar este projeto em sua máquina local de forma simples, abra o terminal e digite os comandos abaixo:

```bash
# Clonar o repositório
git clone https://github.com

# Entrar na pasta do projeto
cd painel-rodoviaria
```

Depois de clonar, basta abrir o arquivo principal (`index.html`) diretamente no seu navegador!
