## 🚀 Como executar o projeto

Para clonar e executar este projeto em sua máquina local de forma simples, abra o terminal e digite os comandos abaixo:

```bash
# Clonar o repositório
git clone https://github.com

# Entrar na pasta do projeto
cd painel-rodoviaria
```

Depois de clonar, basta abrir o arquivo principal (`index.html`) diretamente no seu navegador!
